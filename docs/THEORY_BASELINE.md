# FeedbackPro — теоретический baseline ВКР

Статус: **PROJECT CANON**.

## 1. Предметная логика

Клиентский отзыв рассматривается одновременно как:

- канал обратной связи;
- элемент цифровой репутации;
- источник данных для выявления повторяющихся проблем;
- основание для управленческого/коммуникационного решения;
- объект контроля результата после принятого решения.

Канонический процесс:

**получение → регистрация → классификация → анализ → решение → ответ/мероприятие → контроль → оценка результата**.

## 2. Аналитический контракт

Автоматический анализ FeedbackPro разделяет три независимых характеристики:

1. **тональность** — positive / neutral / negative;
2. **тема/аспект** — multi-label классификация предмета обращения;
3. **критичность** — low / medium / high / critical как оценка приоритета и потенциального репутационного риска.

Негативность не равна критичности. Ручная экспертная верификация не уничтожает автоматический результат и его версию.

## 3. Исследовательская доказательность

Качество классификации оценивается только на фактически экспертно размеченных данных. Контрольная выборка проекта — 300 реальных отзывов из корпуса; фиктивные expert labels запрещены.

Допустимые метрики качества:

- sentiment: confusion matrix, accuracy, precision, recall, F1, macro-F1;
- aspects: micro/macro precision, recall, F1, exact-match ratio;
- criticality: confusion matrix, accuracy, macro-F1, ordinal error.

Тестовые синтетические наборы разрешены только для проверки корректности математической реализации метрик и не являются результатами исследования ВКР.

## 4. Эффект внедрения

Метрики качества классификатора и показатели эффекта внедрения — разные сущности.

Фактические BEFORE/AFTER показатели эффективности FeedbackPro фиксируются только после пилотной апробации. До этого допустимы структура методики, формулы, пустые поля и тестовые технические данные, но не выдуманные результаты.

## 5. Научная база

Утверждённый рабочий корпус научных источников проекта — 40 основных источников: преимущественно российские/русскоязычные и официальные источники, с ограниченным числом иностранных усилителей. При подготовке текста ВКР используются только реально прочитанные и применённые источники; библиографические данные не выдумываются.

Подробный библиографический реестр должен храниться в GitHub отдельным документом/файлом после переноса утверждённого списка в репозиторий.
