## Проверка получения данных

Выполнена отдельная acquisition-проверка:
- File Library — корпус отзывов не обнаружен;
- текущие вложения — корпус не обнаружен;
- подключенный Google Drive — поиск по FeedbackPro/отзывам не дал массива;
- открытый веб — найден реальный Wildberries reference dataset (~27,2 тыс. русскоязычных отзывов, marketplace), но он не является четырехканальным корпусом одной организации N;
- владельческие выгрузки сайта/карт/прямого канала требуют фактического доступа/исходных файлов организации.

Поэтому marketplace reference не используется для искусственного PASS G-T3-09.

## Условие разблокировки

Для фактического закрытия T3 требуется владельческий/пользовательский обезличенный корпус либо исходные выгрузки, позволяющие сформировать 1000–1500 реальных отзывов по утвержденной схеме без подмены объекта исследования.
