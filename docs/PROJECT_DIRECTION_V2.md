# FeedbackPro — направление ВКР v2

С 15.09.2026 ВКР ведётся в теоретико-проектном формате. Официальная тема сохраняется без изменения. Результат работы: теоретическая база, модели, схемы, регламенты, классификаторы, методики, рекомендации и план внедрения.

Дальнейшая кодовая разработка не входит в ВКР. Существующий код и прежние A1–A4 сохраняются как исторический проектный материал.

Нормативная база, все ранее выгруженные требования и рекомендации, а также утверждённые 40 научных источников сохраняются.
