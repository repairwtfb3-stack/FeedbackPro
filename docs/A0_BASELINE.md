# FeedbackPro — A0 baseline

Статус: **ACCEPTED / FROZEN**.

## Паспорт ВКР

Каноническая тема: **«создание программы по работе с отзывами клиентов анализ, моделирование, внедрение»**.

Профиль: «Реклама и связи с общественностью в коммерческой сфере».

Практический результат ВКР — локальная программа FeedbackPro для системной обработки клиентских отзывов: получение/импорт → регистрация → классификация → анализ → решение → ответ/мероприятие → контроль → оценка результата.

## Функциональная граница

MVP включает локальный импорт XLSX/CSV, хранение в SQLite, анализ тональности + темы/аспекта + критичности, решения, контроль, аналитику, отчётность и S01–S10.

Внешние облачные API/LLM не являются обязательной частью MVP. Промышленное внедрение в реальной организации не заявляется как выполненное.

## Эмпирический baseline

- исследовательский объект: модельная обезличенная коммерческая организация N;
- сфера: омниканальная розничная/онлайн-торговля потребительскими товарами;
- целевой корпус: 1200 отзывов;
- допустимый диапазон без пересмотра A0: 1000–1500;
- контрольная экспертная выборка: 300 отзывов;
- период корпуса: 01.09.2025–31.08.2026;
- AS-IS: отсутствует единый системный контур обработки отзывов.

## Апробация

Апробация является пилотной: локальная Windows-установка, импорт корпуса, прохождение полного жизненного цикла и сравнение BEFORE/AFTER по заранее определённым показателям.

**Фактические значения BEFORE/AFTER не задаются и не придумываются до реальной апробации.**

## Нормативное правило

«Программа государственной итоговой аттестации» является нормативной базой проекта. Все решения продукта, текста ВКР, аналитики и защиты должны иметь трассировку в `REQUIREMENTS_MASTER.md` и `TRACEABILITY_MASTER.md`.
