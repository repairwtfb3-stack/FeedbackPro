# FeedbackPro — UI canon S01–S10

Статус: **ACCEPTED / CANONICAL**.

## Визуальный канон

- светлая рабочая область;
- тёмный sidebar;
- синие акценты;
- белые карточки;
- строгий B2B-интерфейс;
- русский язык для пользовательского контента, кроме общепринятых терминов/аббревиатур и кода;
- единая навигация и единый набор состояний loading / empty / error / ready.

## Реестр экранов

| ID | Экран | Назначение |
|---|---|---|
| S01 | Дашборд | сводные KPI, тренды, проблемные зоны |
| S02 | Отзывы | рабочий реестр, поиск, фильтры, сортировка |
| S03 | Карточка отзыва | provenance, auto analysis, expert verification, решения, история |
| S04 | Импорт | CSV/XLSX preview, validation, import batch/result |
| S05 | Решения | реестр решений и приоритетов |
| S06 | Карточка решения | связанные отзывы, статус, срок, действия |
| S07 | Контроль | контроль исполнения, просрочки, outcome, verification |
| S08 | Аналитика | агрегаты, quality metrics, drill-down, экспорт отчёта |
| S09 | Справочники | темы/аспекты и управляемые классификаторы |
| S10 | Настройки | локальные параметры приложения/организации |

## Архитектурные ограничения

1. До отдельного утверждения новый экран S11 не создаётся.
2. Детальные представления и модальные действия размещаются внутри S01–S10.
3. CLI может существовать как технический/диагностический путь, но после A3 пользовательский end-to-end сценарий не должен требовать CLI.
4. Данные UI берутся из локальной БД/сервисов; mock KPI в рабочей версии запрещены.
5. BEFORE/AFTER пилота не отображаются как фактические до реальной апробации.

## Канонический пользовательский путь

S04 Import → S02 Reviews → S03 Review card/verification → S05/S06 Decision → S07 Control → S01/S08 Analytics/Report.
