# Решение по рабочему названию ВКР

Статус: **CANONICAL NAMING DECISION**

Дата: 16.09.2026.

## 1. Рабочее название

Начиная с T5 активное рабочее название авторской организационно-методической разработки:

**«Методика ЕГ»**.

До утверждения окончательного названия это обозначение используется во всех новых активных документах ВКР, схемах, макетах, таблицах, дорожной карте и тексте главы 3.

## 2. Что заменяется

В активном no-code контуре ВКР прежнее рабочее обозначение `FeedbackPro` трактуется как прежнее название той же авторской разработки и далее заменяется на **«Методика ЕГ»**.

Формулировка для текста ВКР:

> «Методика ЕГ» — рабочее название разработанной в ВКР организационно-методической программы системной работы с клиентскими отзывами.

## 3. Что не переименовывается

- GitHub-репозиторий `repairwtfb3-stack/FeedbackPro` остаётся техническим контейнером проекта и источником истории;
- legacy-код, старые software-baseline документы, commit messages и исторические evidence не переписываются задним числом;
- названия файлов T0–T4 могут сохранять технические пути и номера этапов.

Это сделано для сохранения воспроизводимости и истории разработки.

## 4. Правило совместимости

При чтении исторических активных документов до полного текстового рефакторинга:

`FeedbackPro` = прежнее рабочее название → **«Методика ЕГ»**.

Новые документы не должны использовать `FeedbackPro` как актуальное название методики.

## 5. Официальная тема ВКР

Официальная тема не меняется:

**«создание программы по работе с отзывами клиентов анализ, моделирование, внедрение»**.
