# Теоретическая трассировка ВКР v2

Активная цепочка:
**норматив → научный источник → исследовательская проблема → аналитический вывод → проектное решение → схема/регламент/модель → рекомендация → раздел ВКР → приложение/evidence**.

| Этап | Результат | Раздел ВКР |
|---|---|---|
| T1 | научная база, понятийный аппарат, карта источников | глава 1 |
| T2 | теоретическая процессная модель работы с отзывами | глава 1 / основа главы 3 |
| T3 | AS-IS, контент-анализ, выявленные проблемы организации N | глава 2 |
| T4 | TO-BE, классификатор, роли, регламент, KPI, архитектурные и экранные схемы | глава 3 |
| T5 | план внедрения, риски, методика оценки эффективности | глава 3 |
| T6 | полный текст, выводы, приложения | вся ВКР |
| T7 | предзащита, презентация, речь, нормативный контроль | защита |

Код, БД и автоматизированные Gate A2/A3/A4 сохраняются как исторические материалы, но не участвуют в активной цепочке доказательства завершения ВКР.
