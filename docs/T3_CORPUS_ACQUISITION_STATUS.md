## 4. Официальный RuStore CSV API

RuStore документирует CSV-экспорт отзывов приложения за заданный период:

`GET /public/v1/application/{packageName}/comment/export?from={date_from}&to={date_to}`

Для него требуется `Public-Token`, поэтому без полномочий владельца `ru.perekrestok.app` полный официальный CSV получить нельзя.
