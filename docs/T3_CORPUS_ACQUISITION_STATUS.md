## 1. Что было проверено

1. ChatGPT File Library — поиск по FeedbackPro, отзывам, корпусу, CSV/XLSX и последние загруженные таблицы.

4. Открытые публичные источники/датасеты русскоязычных отзывов, пригодные по датам.

Результат: пользовательского или владельческого четырехканального массива отзывов организации N в доступном контуре не обнаружено.

## 2. Найденный реальный открытый источник

Обнаружен открытый датасет `Hplss/wb-review-dataset` на Hugging Face:

- источник отзывов: Wildberries;
- язык: преимущественно русский;
- формат: CSV;
- объем: около 27,2 тыс. отзывов;
- дата записей в наборе: до 25.07.2026;
- лицензия: CC BY-NC-SA 4.0;
- присутствуют поля review_id, product_id, category, rating, text/pros/cons, date.

URL: `https://huggingface.co/datasets/Hplss/wb-review-dataset`

Этот источник может использоваться как **внешний реальный marketplace reference/pilot slice** для проверки codebook и аналитической методики.

## 3. Почему этот датасет не закрывает G-T3-09

Он не является достаточным эмпирическим корпусом организации N, потому что:

1. представляет только один тип канала — marketplace;
2. содержит отзывы множества товаров/продавцов, а не единой обезличенной организации N;
3. не покрывает утвержденные каналы `site`, `review_service/maps`, `direct`;
4. использование его как полного корпуса потребовало бы изменить уже утвержденный объект исследования и методику T3.

Поэтому подмена четырехканального корпуса организации N этим набором **запрещена**.

## 4. Доступность остальных каналов

### Сайт / собственный контур

Владельческие платформы позволяют выгружать отзывы, но требуют доступа к кабинету организации. Например, Яндекс Retail документирует выгрузку отзывов магазина в CSV за выбранный период для пользователя с соответствующей ролью.

URL: `https://yandex.ru/support/retail/ru/index/reviews-check`

### Сервис отзывов / карты

Яндекс Бизнес/Яндекс Товары предоставляют владельцу организации работу с отзывами организации, их фильтрацию и аналитику. Это владельческий контур, а не открытый bulk-export обезличенного корпуса произвольной организации.

URL: `https://yandex.ru/support/business-priority/ru/reviews/reviews`

### Прямой канал

Прямой канал должен происходить из фактической анкеты, формы обратной связи, CRM/службы поддержки или другой собственной точки контакта организации N. Открытым веб-поиском такой массив для модельной обезличенной организации получить невозможно без подмены объекта исследования.

### Дополнительный пример API

RuStore поддерживает CSV-экспорт отзывов приложения за период, но запрос требует Public-Token и packageName владельца приложения.

URL: `https://www.rustore.ru/help/work-with-rustore-api/api-feedback-process/get-csv-feedback`

Это подтверждает общий принцип: крупные платформы позволяют получить реальные массивы, но для репрезентативной владельческой выгрузки нужен доступ владельца/авторизованный экспорт.

## 5. Решение по научной добросовестности

Не выполняется:
- генерация синтетических отзывов;
- смешивание отзывов разных реальных компаний и выдача их за организацию N;
- использование marketplace-датасета как якобы четырехканального корпуса;
- выдумывание распределений по каналам;
- восстановление прямого канала из несуществующих данных.

## 6. Что требуется для фактического empirical run

Минимально нужен один или несколько исходных файлов, суммарно содержащих 1000–1500 реальных обезличенных отзывов за 01.09.2025–31.08.2026 и позволяющих определить утвержденные группы каналов:

- `site` — сайт/форма организации;
- `marketplace` — маркетплейс;
- `review_service` — карты/агрегатор;
- `direct` — анкета/прямой канал.

Форматы: CSV/XLSX/JSON или иные табличные выгрузки, которые можно без потери происхождения привести к `T3_CORPUS_SCHEMA.md`.
